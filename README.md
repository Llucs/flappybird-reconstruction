# Flappy Bird Reconstruction

An independent reconstruction aiming to be **as close as possible to a historical version** of the game, created for study, preservation, and research.

This project was developed by **Llucs** with the assistance of **AI** and analysis tools, including **Apktool** and **JADX**. It is not affiliated with, endorsed by, or published by DotGears, Dong Nguyen, or any other rights holder of Flappy Bird.
